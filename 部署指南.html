🚀 小松工作台 · 部署指南

按以下步骤操作，10 分钟即可拥有自己的工作台

1注册 GitHub 账号

打开 github.com，点击右上角 Sign up，用邮箱注册一个免费账号。

已有账号的直接跳到下一步。

2创建新仓库

登录后点右上角 + → New repository

填写以下信息：

• Repository name 输入：my-workbench（名字可自定义，建议用英文）

• 选择 Public（公开）

• 勾选 Add a README file

• 点击底部绿色按钮 Create repository

💡 仓库名建议用纯英文，不要有空格和中文

3上传 index.html 文件

进入刚创建的仓库，点击 Add file → Upload files

把收到的 index.html 文件拖进去（或点击 choose your files 选择文件）

等待上传完成，滚动到页面底部，点击绿色按钮 Commit changes

⚠️ 文件名必须是 index.html，不要改名

4开启 GitHub Pages

在仓库页面点击顶部 Settings 标签

在左侧菜单找到 Pages（往下滚动可以看到）

在 Source 下拉菜单中选择：

• Branch 选择 main

• 右边选择 /(root)

• 点击 Save

💡 保存后等待 1-2 分钟，页面顶部会出现你的网址链接

5打开你的工作台

你的工作台网址格式为：

https://你的用户名.github.io/my-workbench/

把"你的用户名"替换成你的 GitHub 用户名，在手机浏览器打开即可使用。

💡 建议在手机浏览器中打开后，点击"添加到主屏幕"，就能像 App 一样使用

6添加到手机桌面（可选）

iPhone（Safari）：打开网址 → 点底部分享按钮 → 添加到主屏幕

安卓（Chrome）：打开网址 → 点右上角 ⋮ 菜单 → 添加到主屏幕

添加后桌面会多一个图标，点击即可全屏打开，和原生 App 一样。

7开启云同步（可选）

如果需要多设备数据同步，可以配置 Supabase：

1. 打开工作台 → 点击左侧菜单 数据管理

2. 点击 配置云同步

3. 按 Supabase配置指南.md 中的步骤操作即可

⚠️ 云同步为可选功能，不配置也能正常使用，只是数据只存在手机本地

★常见问题

Q：打开后是白屏？

A：检查文件名是否为 index.html，等待 2 分钟让 GitHub 部署完成。


Q：数据会丢失吗？

A：不会。数据自动保存在手机本地，清除浏览器缓存才会丢失。建议开启云同步备份。


Q：可以修改菜单内容吗？

A：可以。用文本编辑器打开 index.html，找到 const NAV=[ 部分，按格式增删菜单项。


Q：如何修改工作台名称？

A：搜索代码中的"小松"，替换成你想要的名字即可。
