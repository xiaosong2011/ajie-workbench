# 阿杰的工作台 · 男生版

一个基于纯 HTML/CSS/JavaScript 的个人成长工作台，无需后端，数据保存在浏览器本地。

> 🔧 **要接手编辑这个项目？**
> 请先阅读 **[小松工作台-接手配置指南.md](小松工作台-接手配置指南.md)**，包含完整的项目结构、配置常量、函数索引和编辑指南。

## ✨ 功能特性

### 17 个功能板块
- 📅 **每日计划** — 待办事项 + 签到日历
- 👨‍👦 **亲子时光** — 带娃时间表与任务
- 📚 **技能充电** — 技术学习路径与书单
- 💪 **力量训练** — 健身计划与记录
- 📖 **英语进阶** — 英语学习方法
- 🎙️ **播客精选** — 优质播客推荐
- 🗣️ **表达能力** — 每日练习清单
- 📕 **读书推荐** — 月度书单与已读记录
- 🧔 **理容穿搭** — 护肤与穿搭指南
- 💰 **副业搞钱** — 副业方向与原则
- 🤖 **AI学习** — AI 工具与学习路径
- 📰 **行业资讯** — 信息源与要点
- 📝 **每日复盘** — 复盘记录（支持增删改查）
- ⭐ **灵感收藏** — 灵感库（支持增删改查）
- 📊 **小账本** — 支出记录（支持增删改查）
- 🎮 **数码电竞** — 装备清单
- ☀️ **天气** — 天气与穿衣建议

### 增删改查（CRUD）
以下模块支持完整的增删改查，数据通过 `localStorage` 持久化保存：
- **待办事项** — 新增、编辑（双击）、完成/取消、删除
- **每日复盘** — 新增、编辑、删除
- **灵感收藏** — 新增、编辑、删除
- **小账本** — 新增、删除、自动汇总与占比计算

### 数据管理
- 💾 **导出备份** — 一键导出全部数据为 JSON 文件
- 📥 **导入恢复** — 从 JSON 文件恢复数据
- 🗑️ **清空重置** — 清空所有数据（需二次确认）

### 其他特性
- 📱 移动端响应式设计，支持抽屉式导航
- 📲 支持添加到手机主屏幕（PWA 模式）
- 🎨 蓝绿色系男生风格 UI
- ⚡ 纯前端，无需服务器，打开即用

## 🚀 使用方法

### 在线访问
通过 GitHub Pages 访问：
```
https://<你的用户名>.github.io/<仓库名>/
```

### 本地使用
直接用浏览器打开 `index.html` 即可。

### 添加到手机主屏幕
1. 用 Safari 打开页面
2. 点击底部「分享」按钮
3. 选择「添加到主屏幕」
4. 点击「添加」

## 🛠️ 技术栈
- HTML5 + CSS3 + 原生 JavaScript
- localStorage 数据持久化
- 响应式设计（移动端优先）
- PWA Meta 标签
